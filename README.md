# quadcopter-matlab-simulation

# MATLAB Quadcopter Modelling and Control

MATLAB-based simulation of a 6-DOF quadcopter using rigid-body dynamics and PID control.

## Current Features

- 12-state quadcopter dynamic model
- Newton-Euler equations of motion
- Roll, pitch, yaw and vertical velocity PID control
- Real-time 3D drone visualization
- Position and velocity plots
- Euler angle and angular-rate plots
- Thrust and control-moment plots
- Live 3D trajectory tracking
- Simulation data export to Excel for future data-driven / ML applications

## Project Status

This project is currently under development as part of a study-oriented project on drone modelling and autonomous disaster search and rescue.
